Vamos a trabajar la **fase $ARGUMENTS** de la web v3 de marcelagotta.com.

1. Lee `CLAUDE.md` y `design/v3/HANDOFF.md`: la sección 7 para el alcance de la fase, y las secciones 1 a 6 para el detalle que necesite.
2. Abre del prototipo solo lo que haga falta: `design/v3/prototype/Main.dc.html` y `design/v3/extracted/` (styles.css, markup.html, logic.js). Copia de ahí las medidas, los colores, los tiempos y las constantes físicas exactas.
3. Antes de escribir código, enséñame un plan breve: qué vas a crear o cambiar y en qué orden. Espera mi OK.
4. Implementa solo esta fase. Si algo del prototipo no se puede trasladar tal cual, pregúntame.
5. Verifica:
   - `npm run lint`, `npm run typecheck`, `npm run test` y `npm run build` sin errores. En la fase 0, deja creados esos scripts.
   - Si la fase toca la interfaz, revísala en el navegador a 1440 y 390 px, con tema oscuro y claro, en ES y EN, y con `prefers-reduced-motion`.
6. Haz un commit de la fase y termina con un resumen: lo hecho, lo pendiente y las decisiones que necesiten mi visto bueno.
